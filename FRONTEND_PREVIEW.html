Provider Agnostic

❓ Q&A System

RAG + Semantic Search

Ask physics questions, get AI-generated answers with source citations from uploaded documents.

📚 Knowledge Management

OCR + Embeddings

Upload PDFs/images, automatic text extraction, semantic chunking, vector embeddings (pgvector).

ELO Rating System

Adaptive problem selection (80/20 weak/strong), ELO-based difficulty, mastery tracking.

📊 Progress Dashboard

Real-time Analytics

Mastery distribution, weak area identification, 30-day activity history, success rates.

🌟 Key Differentiators

✓ Provider Agnostic: Works with Claude, OpenAI, Gemini (user-provided keys)
✓ Security First: AES-256 encryption, server-side keys, no secrets exposed
✓ Hebrew RTL: Built for right-to-left languages from day 1
✓ Extensible: Physics → Math → Chemistry (data-driven, no code changes)
✓ RAG + Citations: AI answers cite their sources (reduces hallucination)
✓ Adaptive Learning: ELO system (proven in chess, Duolingo)
