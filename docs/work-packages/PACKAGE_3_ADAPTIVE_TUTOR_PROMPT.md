# SmarterAI — חבילה 3: מורה אנושי, מסתגל ומבוסס מקורות

## מטרת העל

לשדרג את SmarterAI ממנוע תשובות למורה אישי שמסביר לפי המקצוע, הרמה, הידע והעדפות התלמיד; מזהה טעויות, מתאים את ההסבר ומבסס תשובות על מקורות אמינים עם ציטוטים.

## תנאי פתיחה

- חבילות 1–2 הושלמו והמערכת יציבה.
- קיימים מקצוע, רמת יח״ל, טקסונומיית נושאים ומאגר מקורות מסווג.
- כל ספקי ה־AI מחוברים רק דרך `AIGateway`.

## דרישות

### 1. סגנונות הוראה

- להציע שלושה מצבים: “חד וקולע”, “מאוזן ומסביר” ו“מעמיק עם דוגמאות”.
- ברירת המחדל תהיה “מאוזן ומסביר”.
- הסגנון משנה אורך, קצב, מספר דוגמאות ואנלוגיות, אך לא נכונות או דרגת לימוד.
- הטון הבסיסי יהיה חם, מכבד, מעודד ולא מתיילד.
- הומור יהיה עדין ולעיתים רחוקות, ולא יופיע במצבי תסכול, כישלון או נושא רגיש.

### 2. התאמה לתלמיד

- לזכור, בהסכמה ובשקיפות, נושאים שנלמדו, טעויות חוזרות, שליטה והעדפת הסבר.
- לאפשר צפייה, תיקון ומחיקה של הזיכרון הלימודי.
- לזהות סוג טעות: מושגית, אלגברית, חישובית, קריאת שאלה או בחירת אסטרטגיה.
- להציע הסבר חלופי, רמז מדורג או תרגיל קצר במקום לחזור על אותה תשובה.
- להימנע ממתן פתרון מלא מיד כאשר מטרת המצב היא למידה מודרכת.

### 3. מבנה תשובה

- לפתוח בזיהוי קצר של המשימה ומה ידוע.
- לפרק פתרון לשלבים ברורים ולהסביר למה כל שלב נדרש.
- לסמן נקודת טעות אפשרית ובדיקת היגיון בסוף.
- להציע “למה זה עובד?”, “דוגמה מהחיים” או “תרגיל דומה” לפי הצורך.
- להציג נוסחאות באופן תקין ב־RTL וללא רעשי Markdown/LaTeX.

### 4. RAG ומקורות

- לשלוף מקורות לפי מקצוע, יח״ל, נושא, אמינות, עדכניות וזכויות שימוש.
- לתת עדיפות למשרד החינוך, קמפוס IL, מקורות אקדמיים וספקי סימולציות רשמיים.
- כל טענה המבוססת על חומר לימודי תציג ציטוט שניתן לפתוח.
- כאשר אין מקור מתאים, לומר זאת ולא להמציא ציטוט.
- לשמור provenance לכל מקטע ולמנוע ערבוב בין מקצועות ורמות.

### 5. בטיחות, פרטיות וספקים

- כל קריאת AI עוברת דרך `AIGateway` עם חוזה פלט אחיד.
- אין מפתחות API בצד הלקוח או בלוגים.
- זיכרון התלמיד יכיל רק מידע לימודי נחוץ ויהיה ניתן למחיקה.
- יש להגן מפני prompt injection שמגיע ממסמכים ומקורות חיצוניים.
- יש לתעד עלות, זמן תגובה ושיעור כשל בלי לתעד מידע רגיש.

### 6. הערכה שיטתית

- ליצור סט הערכה קבוע בפיזיקה ובמתמטיקה 3/4/5 יח״ל.
- למדוד נכונות, התאמה לרמה, בהירות, איכות עברית, שימוש במקורות וזמן תגובה.
- לבדוק את אותה שאלה בשלושת סגנונות ההוראה ולוודא שההבדל מורגש אך התוכן עקבי.
- להוסיף בדיקות נגד המצאת מקורות, פתרונות שגויים, רמזים חושפי תשובה וזליגת הקשר.

## הצעות חוויה משלימות

- אבחון קצר בתחילת מסלול והצעת תוכנית שבועית.
- “מחברת טעויות” עם תרגול חוזר במרווחים.
- כפתור “הסבר בדרך אחרת” והרחבה “למה השלב הזה?”.
- מעבר טבעי בין הסבר, דוגמה, תרגול ומשוב.
- סיכום התקדמות מעשי: מה השתפר ומה הצעד הבא.

## קריטריוני קבלה

- ההבדל בין שלושת הסגנונות ברור ועקבי.
- המורה מתאים תשובות למקצוע, יח״ל ושליטת התלמיד.
- טעויות מקבלות אבחון ורמזים מדורגים, לא רק תשובה סופית.
- ציטוטים אמיתיים, פתיחים ורלוונטיים מוצגים כאשר נעשה שימוש במקור.
- המשתמש שולט בזיכרון הלימודי שלו.
- בדיקות הערכה, אבטחה, נגישות, RTL, ביצועים וקוד עוברות.

## תוצר מסירה

- מנוע פרופיל הוראה מונחה־קונפיגורציה.
- זיכרון לימודי שקוף וניתן למחיקה.
- RAG עם ציטוטים ומדדי איכות.
- דוח הערכה לפני/אחרי ו־Preview לבדיקת בעל המוצר.
